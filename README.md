# פורטל הטבות ומבצעים של כרטיס UNIQ (UNIC / MAX)

פורטל רספונסיבי מודרני מותאם עברית (RTL) המאגד, מסנן ומצליב הטבות של מועדון UNIQ / MAX Executive / TAU:
1. **לשונית א' - כרטיס נטען 15% הנחה:** כל הרשתות המשתתפות, תנאים כלליים (טעינה יומית/חודשית, תקרות יתרה), סייגים, החרגות סניפים, ותגים ויזואליים. המידע מאומת ישירות מול קובץ ה-PDF הרשמי של Max.
2. **לשונית ב' - הטבות לפי מוצר:** שוברים, כרטיסים ומוצרים במחירי מועדון מסונכרנים חי מאתר UNIQ.
3. **לשונית ג' - הנחות רשתות ומותגים:** מבצעים והנחות ברשתות מובילות ואתרי אונליין.
4. **לשונית ד' - הנחות במעמד החיוב:** הנחות אוטומטיות בדף פירוט חיובי האשראי (1% עד 50%).

---

## תכונות מרכזיות
- **אינדיקטורי סטטוס ייעודיים בפינה הימנית העליונה:**
  - 🟢 **אתר UNIQ (חי):** מציג את תאריך ושעת העדכון האחרונים מתוך ה-metadata של `scraped_benefits.json`, עם נקודת פעימה חיה וחלון פרטים (Tooltip) מפורט.
  - 🟢 **ספח Max (כרטיס נטען 15%):** מציג את מועד אימות ספח ה-PDF העדכני מתוך ה-metadata של `rechargeable_benefits.json` ו-SHA256 של הקובץ.
- **סקרייפרים נפרדים וייעודיים:**
  - `scripts/scrape_max_pdf.py`: סקרייפר ייעודי להורדה ואימות ישיר של ספח ה-PDF מכרטיסי Max (`gc-ex-digital.pdf`).
  - `scripts/scrape_uniq_site.py`: סקרייפר ייעודי לסריקת ה-GraphQL API של אתר `uniq-club.co.il` על כל הקטגוריות.
  - `scripts/scraper.py`: מתאם (Orchestrator) המריץ את שני הסקרייפרים ומצליב ביניהם.
- **מנוע הצלבה בין לשוניות (Cross-Referencing Engine):** תגיות אינטראקטיביות עבור מותגים המופיעים ביותר מלשונית אחת (למשל: תקף גם בכרטיס נטען וגם בהנחה במעמד החיוב). לחיצה על תגית מעבירה ישירות ללשונית היעד ומדגישה את הכרטיס המתאים.
- **סינון וחיפוש עברי מהיר:** חיפוש דינמי לפי שם מותג, קטגוריה, סוג הנחה או מגבלה.
- **סיווג ויזואלי של מגבלות:**
  - 🔴 **אדום:** החרגות מלאות (ללא אאוטלט, לא תקף בדיוטי פרי, ללא כפל מועדון, ללא סניף אילת).
  - 🟡 **צהוב:** תקרות שימוש וסכום (הגבלה עד 500 ₪, עד 50% מסכום העסקה, עד 1,000 ₪).
  - 🔵 **כחול/אפור:** כללי תפעול (הזמנה טלפונית בלבד, איסוף עצמי בלבד, כפל מבצעים).
- **נתונים אמיתיים (ללא מוקים):**
  - `public/data/rechargeable_benefits.json`: מאומת ישירות מול ספח ה-PDF הרשמי של Max.
  - `public/data/scraped_benefits.json`: מעל 340 פריטים שנסרקו ישירות מה-GraphQL API של אתר `uniq-club.co.il`.
- **אוטומציה שבועית:** GitHub Actions Workflow (`.github/workflows/scrape.yml`) הפועל מדי יום ראשון בחצות ומעדכן את המאגר.
- **פריסה אוטומטית:** GitHub Actions Workflow (`.github/workflows/deploy.yml`) לפריסה ב-GitHub Pages.

## פקודות הרצה ובדיקה

```bash
# התקנת תלויות
npm install

# הפעלת שרת פיתוח מקומי
npm run dev

# הרצת בדיקות יחידה ואינטגרציה (Vitest + RTL)
npm test

# הרצת בדיקות שלמות נתונים וסקרייפר (Pytest)
npm run test:python

# בנייה לפרודקשן
npm run build

# הרצת הסקרייפר לעדכון הנתונים
python3 scripts/scraper.py
```
